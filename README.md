# Alhaq Digital Services Website

Building a Digital Future, Rooted in Faith.

## Overview

Alhaq Digital Services (ADS) is a professional website that leverages modern web technologies to create meaningful digital tools that enrich our connection to the Deen (Islamic faith). This repository contains the source code for the official ADS website.

## Features

### Core Services
- **Taleem AI**: AI-powered Quran recitation feedback and memorization practice
- **Islamic Library**: Access to Islamic books, infographics, and educational resources
- **Custom Islamic Apps**: Mobile and web applications for Islamic education and community

### Technical Features
- Responsive design optimized for all devices
- Multi-language support (English, Arabic, Dari/Persian)
- Modern glassmorphism UI design
- Islamic-themed styling and patterns
- SEO optimized
- Accessibility compliant

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Tailwind CSS with custom Islamic design system
- **Fonts**: Inter (Latin), Amiri (Arabic)
- **Build Tools**: npm, ESLint
- **Development Server**: live-server, Python HTTP server
- **Version Control**: Git

## Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)
- Python 3 (for development server)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/AlhaqGH/alhaq-website.git
cd alhaq-website
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
# or
npm run serve
```

4. Open your browser and navigate to `http://localhost:8080`

## Available Scripts

- `npm start` - Start the Node.js server (if applicable)
- `npm run serve` - Serve the website using Python HTTP server
- `npm run dev` - Start development server with live reload
- `npm run lint` - Run ESLint to check code quality

## Design System

### Brand Colors
- **Primary Blue**: `#0A2540` - Used for headers and primary text
- **Brand Gold**: `#D4AF37` - Used for accents and call-to-action elements
- **Background**: `#F8F9FA` - Clean, light grey background

### Typography
- **Primary Font**: Inter - Modern, clean sans-serif for Latin text
- **Arabic Font**: Amiri - Traditional, readable serif for Arabic text

### UI Components
- **Glass Cards**: Modern glassmorphism effects for content containers
