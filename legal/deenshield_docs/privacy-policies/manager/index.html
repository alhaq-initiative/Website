Desktop Manager Privacy Policy

Product: DeenShield Desktop Manager / Launcher • Developer: Alhaq Digital Services (ADS)
Effective Date: August 12, 2025 • Version 1.0

The Desktop Manager unifies access to other DeenShield products. Current release is lightweight with no outbound personal data transmission. Planned features are noted below.

1. Introduction

The Manager provides a single interface to launch the Web App, Extension controls, and (future) Desktop / Mobile integrations, plus consolidated shortcuts and notifications.

2. Local Data Elements

  • UI State: Last active panel, window sizing.
  • Shortcut Configuration: Hotkeys stored locally.
  • Notification Preferences: Enable/disable toggles for aggregated reminders.
  • Integration Hooks (Planned): Local references to extension presence / web app URL.

3. No Central Collection

No telemetry, no remote logging, and no analytics calls are performed by default.

4. Planned Optional Features

  • Unified Sync (Planned): Opt‑in encrypted sync of preferences.
  • Cross‑Device Presence (Planned): Optional indicator showing which devices are active (requires account system, not yet launched).
  • Aggregated Metrics (Possible): On-device only or privacy-preserving if ever enabled (off by default).

5. Security

  • Local configuration files stored in user profile directory.
  • No privileged OS access beyond what you permit.
  • Future sync (if enabled) will use end‑to‑end encryption.

6. Children & Age Guidance

Not specifically targeted at children; contains no child‑directed content. Family use acceptable with supervision.

7. Your Control

  • Delete configuration by removing the app data directory or uninstalling.
  • Reset settings via in‑app reset (planned).
  • All optional features default to off.

8. Ethical Alignment

  • No dark patterns or hidden background services.
  • Designed for clarity and user empowerment.

9. Updates

Material changes will be highlighted in release notes and on the unified overview page.
