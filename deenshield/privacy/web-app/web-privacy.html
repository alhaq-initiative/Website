Web Application Privacy Policy

Product: DeenShield Web App • Developer: Alhaq Digital Services (ADS)
Effective Date: August 12, 2025 • Version 1.1

Introduction

The DeenShield Web App provides prayer times, Quran reading, dhikr counter, and productivity tools. We designed it to run entirely client‑side with settings stored locally to preserve your privacy.

What Information We Collect

  • Local Preferences: Theme, last active section, calculation method selections.
  • Prayer Location Data: If you allow location (future feature) it is processed in-browser to compute prayer times; coordinates are not transmitted to ADS.
  • Quran Reading State: Last surah / ayah, bookmarks, and progress markers stored in localStorage.
  • Tasbih / Dhikr Counts: Stored locally for your reference only.

What We Do NOT Collect

  • No account credentials (accounts not required in current version).
  • No remote logging of prayer times usage, Quran progress, or dhikr counts.
  • No advertising or behavioral analytics scripts.

How We Use Your Data

  • Preferences personalize interface and calculations.
  • Reading progress enables continuity across sessions on the same device.
  • Dhikr counters exist solely for your on‑device reflection.

Permissions / APIs

  • Local Storage: Save settings, state, and counters.
  • Geolocation (Future Optional): Only used client‑side to compute prayer times; not sent externally.
  • Notification API (Planned): Local prayer reminders – no server push.

Data Security

  • Runs as a static client app: no server session state.
  • Clearing browser data removes all stored values.
  • No centralized database to breach for current version.

Your Rights

  • Clear data by using browser storage clearing tools.
  • No account means no central profile to delete—control resides entirely with you.
  • Open / auditable source fosters trust.

Children & Age Guidance

Family-friendly. We do not knowingly collect personal data from children. Parents supervising use can clear the browser storage anytime. Should future sync or profiles launch, additional safeguards and parental controls will be documented.

Islamic Compliance

  • Amanah & integrity: No hidden trackers.
  • Focus on beneficial knowledge & productivity.
  • Respect for user autonomy and modesty.

Updates

Future new features (cloud sync, multi‑device) will include an explicit in‑app notice before collecting any additional data.
