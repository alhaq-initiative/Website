Desktop App Privacy Policy

Product: DeenShield Desktop Application • Developer: Alhaq Digital Services (ADS)
Effective Date: August 12, 2025 • Version 1.0

The desktop app focuses on offline productivity & protection. Current build keeps data on your device. Planned features are clearly labeled.

1. Introduction

The Desktop App delivers richer offline capabilities (full Quran package, offline prayer calculations, integrated protection controls). Privacy is preserved by processing locally.

2. Local Data Stored

  • Configuration: Window size, theme, last dashboard view.
  • Quran Assets: Locally cached text / translation packages.
  • Progress & Bookmarks: Stored in local app data folder as JSON / small DB.
  • Prayer Calculation Parameters: Method, madhhab, adjustments.
  • Optional Protection Rules: Local bridging to extension (if installed) – no upload.

3. What We Do NOT Collect

  • No keystroke logging, screen capture, or browsing history.
  • No remote telemetry / analytics by default.
  • No sale or sharing of configuration or religious usage data.

4. Planned Optional Features

  • End‑to‑End Encrypted Sync (Planned): Multi-device Quran progress & settings.
  • Focus Session Cloud Backup (Planned): Optional; disabled by default.
  • Anonymous Stability Metrics (Possible): Crash signatures with user opt‑in.

5. Security

  • Local files stored under user profile with OS permissions.
  • No elevated privileges unless user grants (e.g., autostart toggle).
  • Future sync endpoints will require strong encryption & key derivation.

6. Children & Age Guidance

General audience utility. No data from children is collected intentionally. Guardians can remove local app data or uninstall to clear usage artifacts.

7. User Control

  • Delete local data by using in‑app reset (planned) or purging app data directory.
  • Remove cached translations individually (planned UI) or via file system.
  • Opt‑in for any remote features; default state is fully offline.

8. Ethical Alignment

  • Honors Islamic principles of privacy & modesty.
  • No addictive gamification loops.

9. Updates

Policy updates versioned; material changes flagged in release notes and overview.
